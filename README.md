# Simple Calculator 🧮

A beginner-friendly calculator built using **HTML**, **CSS**, and **JavaScript**.  
It currently supports basic arithmetic operations like:

- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)

## 🧪 Current Features

- Clean and responsive design
- Clickable buttons for input
- Basic error handling (like divide by zero)

## 🔮 Planned Features (Coming Soon)

- Support for keyboard input (typing numbers and operators)
- Better error handling and display
- Dark mode toggle
- Percentage and backspace functionality

## 🧠 Learning Purpose

This project was created to practice and understand the basics of:

- HTML layout structure
- CSS styling and responsiveness
- JavaScript DOM manipulation and event handlin.
